# Archive scope

The scientific scripts and scientific settings are retained. Two portability changes are intentional: pipeline_utils accepts a safe runtime example and environment overrides; local_rat.json now carries investigator-confirmed H9c2 identity and exposure metadata. Neither changes count matrices, sample membership, model formulas, statistical thresholds or ranking rules.

Paper-writing scripts and desktop-specific illustration/report recovery are excluded. A missing paper-rendering helper mentioned by a historical report module does not affect the underlying statistical source; see the inventory. Final submission artifacts and unpublished figure/result data are maintained separately from this public-code folder.

No software licence, author identity, repository URL or DOI has been invented. This folder may be uploaded as a code archive, but an explicit reuse licence is still for the rights holders to select.
